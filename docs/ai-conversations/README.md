## 3. 後續最小保存規則

1. 優先使用平台現有且被允許的正式匯出／下載功能；若之後工具能直接取得全文，由助理保存並更新本索引，不要求使用者逐輪處理。
2. 匯出保留使用者 Prompt、Codex 完整回覆、原始順序、程式碼與可取得的工具結果。不得省略失敗嘗試後仍稱為完整紀錄。
3. 保留原始匯出檔，不覆寫。若有格式轉換或必要遮蔽，另存衍生檔並註明方法、遮蔽或缺漏範圍，不冒稱未刪節原件。
4. 對話檔可依「日期－步驟範圍－來源分頁」命名，副檔名依實際匯出格式；尚未建立的檔名不填入現有檔案索引。
5. 每次加入真實匯出檔後，索引記錄實際檔名、來源分頁、涵蓋步驟、保存日期、匯出方法、是否含工具輸出及已知缺漏。
6. 模型名稱與思考等級只能記錄該次對話可確認的設定與來源。無法核對就寫「未確認」；其他分頁設定不得作為本輪設定。
7. 開發摘要仍更新同一份 `docs/development-log.md`；摘要與全文分開管理，不拿摘要替代老師要求的完整對話。
8. 不讀取或輸出 API Key、密碼、Token、實際 `.env`、帳戶驗證資料或內部資料庫，不為取得全文繞過工具或平台限制。
